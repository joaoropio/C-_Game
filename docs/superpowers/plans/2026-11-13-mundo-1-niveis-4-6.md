## Review Focus

1. Ciclos escondidos na condição de outro ciclo, no cabeçalho de um `for` ou na expressão de um `foreach` (ex.: lambda com `while (true)` dentro de `while (F())`) têm de ser travados pelo contador, não só pelo limite de 3 s. Task 1.
2. Um `for` com o contador errado (`<` vs `<=`, começar em 0 vs 1) é o erro mais provável do nível 4: a mensagem de validação tem de dizer o resultado esperado e o obtido para cada caso. Task 2.
3. Array vazio no nível 5 e índice fora do array (`potions[potions.Length]`): o primeiro tem de ser um caso validado; o segundo tem de dar a explicação amigável já existente (`IndexOutOfRangeException`). Task 3.
4. Strings: `name[0]` devolve `char`, não `string`; misturar `char` com `int` num `+` dá um número em vez de texto. A explicação/dica do nível 6 tem de prevenir isto. Task 4.
5. A ordem e o desbloqueio: o nível 4 só abre depois do 3; o mapa mostra 6 salas. Coberto pelos testes existentes de `PlayerProgress`/Home; confirmar no browser no fim.

### Task 4: Nível 6 — strings

**Files:**
- Create: `content/levels/06-strings/{…}`, `content/grimoire/strings.json`
- Test: `tests/CodeQuest.Tests/Levels/LevelSolutionTests.cs`

Conteúdo:
- Mundo 1, nº 6, página `strings`, máx. 1 instrução. (Nota: o limite de 3 estrelas foi publicado como 3, por decisão, e não 1.)
- Template: `public static class Spell { public static string SealCode(string name) { … } }`.
- Regra: o código do selo é a primeira letra de `name` em maiúscula seguida do número de letras.
- Verificações: `"merlin" → "M6"`, `"Ana" → "A3"`, `"z" → "Z1"`, `"morgana" → "M7"`; mensagens com o nome, o esperado e o obtido.
- Starter: `return name;`.
- Solução: `return char.ToUpper(name[0]) + name.Length.ToString();` (ou interpolação `$"{…}{…}"`). A história e as dicas explicam `name[0]`, `Length`, `ToUpper` e como juntar texto.
- Conceito: uma string é texto; `Length`, `[i]`, `ToUpper()`, `+` e interpolação `$"…{x}…"`. Mini-exemplo noutro tema. Aviso: `name[0]` é um `char`; somar `char + int` dá um número — usar interpolação ou `ToString()`.
- Grimório `strings`: `Length`, índice, `ToUpper`/`ToLower`, `+`, interpolação; exemplo noutro tema; erros comuns (`char + int` dá número, strings não mudam — `ToUpper` devolve uma nova, índice começa em 0); `learnUrl` de strings.

- [ ] **Step 1:** Testes: `Level6_CharPlusInt_ExplainsWhatWentWrong` (`return (char.ToUpper(name[0]) + name.Length).ToString();` → `ChecksFailed` cuja mensagem mostra o esperado e o obtido, ex.: "M6" vs "83"); `Level6_Interpolation_Passes` (`return $"{char.ToUpper(name[0])}{name.Length}";` → `Passed`).
- [ ] **Step 2:** RED. **Step 3:** Conteúdo. **Step 4:** GREEN + suite completa.
