# Code Quest — Mundo 2 "Organizar o código": plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Cinco níveis novos no segundo andar da masmorra — métodos, sobrecarga e parâmetros opcionais, exceções, `List` e `Dictionary` — cada um com vinheta, página no Grimório e testes; e o motor/UI preparados para o jogador escrever os seus próprios métodos.

**Architecture:** No Mundo 2 o marcador `// {{PLAYER_CODE}}` passa a poder estar **ao nível da classe** (o jogador escreve métodos dentro de `Spell`, sem ver `class`/`using`/`namespace`). O motor tem de guardar esses corpos de métodos contra recursão e ciclos, contar instruções corretamente e explicar os erros novos (método em falta, número de argumentos, assinatura duplicada). Os níveis continuam a ser só conteúdo.

**Tech Stack:** .NET 10 (`net10.0`, SDK 11), Roslyn, Blazor, xUnit, bUnit, Playwright.

**Spec:** `CLAUDE.md` (roteiro: "Mundo 2 – Organizar o código: métodos; sobrecarga e parâmetros opcionais; exceções; List e Dictionary").

## Review Focus

1. Recursão infinita entre métodos do jogador (`static int A() => B(); static int B() => A();`) e um método que se chama a si próprio têm de dar a explicação de recursão, nunca derrubar o servidor. Task 1.
2. Código do jogador que tenta fechar a classe (`}`) e declarar tipos/namespaces fora dela continua rejeitado; um `class` aninhado dentro de `Spell` também (o Mundo 2 não ensina classes). Task 1.
3. Erros novos mais prováveis do iniciante — método com nome errado, número de argumentos errado, falta de `static`, duas versões com a mesma assinatura — têm explicação amigável PT/EN. Task 2.
4. Exceções: um `catch` do jogador não pode engolir a proteção de ciclos/recursão (já garantido pelo `Tripped`); uma exceção não apanhada do jogador vira `RuntimeError` com explicação, não crash. Task 6.
5. Mapa com dois mundos: o andar 2 aparece trancado até acabar o Mundo 1, com o trilho certo, e os nomes/andares por mundo. Task 3.
